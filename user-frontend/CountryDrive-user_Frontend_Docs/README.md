# Country Drive Frontend Documentation Pack

This folder contains the Markdown specifications for building the Country Drive frontend while a separate developer builds the backend.

## Files
- `features.md` — complete customer, vendor and admin feature inventory.
- `PRD.md` — frontend product scope, user journeys and acceptance criteria.
- `architecture.md` — suggested frontend structure and API boundaries.
- `Design.md` — glossy UI, responsive design system and accessibility.
- `Task.md` — phased implementation checklist.
- `coding-standard.md` — React, API, form, styling and security standards.
- `ruler.md` — rules for Antigravity/AI coding agents.
- `memory.md` — persistent project context and handoff notes.
- `API_INTEGRATION.md` — backend contract coordination checklist.

## How to use
1. Extract/copy this folder into the frontend repository root.
2. Ensure the main `features.md` is available to Antigravity.
3. Open the existing frontend repository in Antigravity.
4. Ask it to read all Markdown files first, inspect the codebase, and implement frontend pages only.
5. Coordinate the API contract with the backend developer before replacing development fixtures.
6. Run the build and test all routes at mobile, tablet and desktop widths.

These documents define the intended implementation. They do not mean the application or backend has already been implemented.
